  1. Paso 4 - Instalación de librerías para manejar el RTL-SDR

Para solucionar ese tipo de mensaje ejecutar los siguientes comandos desde la terminal.

sudo pip install pyrtlsdr==0.2.92

echo 'blacklist dvb_usb_rtl28xxu' | sudo tee /etc/modprobe.d/blacklist-rtl.conf

sudo reboot

sudo apt update

sudo apt upgrade -y

git clone https://github.com/osmocom/rtl-sdr.git

cd rtl-sdr

mkdir build && cd build

cmake ..

make -j4

sudo make install

sudo ldconfig
